ZC 离线翻译 · 便携版使用说明

一、启动
1. 推荐双击本目录中的“启动翻译器.bat”：它会先定位模型目录，再启动 ZCTranslate.exe，并把参数原样传给它。
2. 如果中文文件名在解压后显示为乱码，可双击同目录的 Start-ZCTranslate.bat（纯 ASCII 名称，作用相同）。
3. 也可以直接双击 ZCTranslate.exe：包内的 models-path.txt 记录了模型目录，应用会读取它。
4. 模型不随包复制；模型位置变化后，编辑 models-path.txt，或把 models 放到本目录。

一（补充）、托盘与划译
1. 点击窗口关闭、Alt+F4 或任务栏关闭只会隐藏到系统托盘，Uvicorn、数据库和翻译模型继续运行；关闭有“关闭到托盘”提示。
2. 左键/双击托盘图标恢复窗口；右键菜单可“打开主窗口”“划译（选中文字自动翻译）”“退出”。要真正结束程序请用托盘菜单的“退出”。
3. 划译默认关闭，可在设置页或托盘右键菜单开启；目标语言在设置页选择，模型和推理设备沿用当前选择，不会另起模型。
4. 划译只对支持 Windows UI Automation 的选区生效，不会模拟 Ctrl+C 或改写剪贴板；部分应用、管理员窗口可能读不到选区。
5. 应用已在运行时再次双击启动器，只会唤起已有窗口，不会启动第二份模型。若托盘图标被隐藏，可使用这种方式恢复。

二、模型目录（不随包复制）
直接双击 exe 时，应用按以下顺序解析 models 目录：
1. 环境变量 ZC_MODELS_DIR（若设置且目录存在）
2. 本目录下的 models\（把模型放进包内，最便携）
3. 本目录的 models-path.txt（默认指向 __ZC_WORKSPACE_MODELS__）
4. data\models（默认回退，通常为空）

用启动器启动时，启动器还会额外查找上一级/上两级目录的 models\，并把命中的目录设为 ZC_MODELS_DIR。

需要自定义时，可以：
- 编辑本目录的 models-path.txt（绝对路径，或以本目录为基准的相对路径，如 ..\models）
- 启动时追加参数：启动翻译器.bat --models-dir D:\models
- 或先设置环境变量 ZC_MODELS_DIR，再运行启动器
- 或把整个 models 文件夹复制到本目录（模型约 2-7 GB，按需选择）

三、数据目录
1. 设置、术语库、历史、翻译记忆和 OpenVINO 编译缓存都在本目录的 data\ 下。
2. 首次启动会自动创建 data\；首次在 NPU 上加载模型需要编译，之后走 data\cache。
3. 删除 data\ 即可恢复默认设置（历史与缓存一并清空）。
4. 整个文件夹可以整体移动；data\ 会跟着走。

四、运行环境
1. Windows 11 x64；WebView2 运行时（Win11 通常已自带）。
2. Intel NPU / GPU 驱动；没有 NPU 时会自动回退 GPU 或 CPU。
3. 首次运行可能被 Windows SmartScreen 拦截：点击“更多信息”→“仍要运行”。本 exe 未做代码签名。
4. 请把本目录放在可写的本地磁盘；不要放在 Program Files、只读共享或网络盘上，否则 data\ 无法写入。

五、离线
应用默认不访问网络。翻译模型、前端资源、OCR 模型和已下载的语音模型都在本机；模型准备完成后断网可正常使用。语音模型只有在用户点击下载按钮时才会联网下载。

六、OCR 与截图翻译
1. 已内置 RapidOCR、ONNX Runtime、PyMuPDF 及 OCR 模型，无需再安装。
2. 截图翻译使用 Windows 截图工具（Win+Shift+S）。请确认“截图工具”已开启“自动复制到剪贴板”，否则应用会提示开启。
3. 图片翻译会在原图上覆盖译文；TXT、MD、扫描 PDF 和 DOCX 会在原文件同目录生成“原文件名_翻译”文件，原文件保持不变。
4. DOCX 会在后台逐段翻译，显示进度并可取消；取消不生成半成品，长文档建议使用 1.8B 档。

七、迁移到另一台机器
1. 复制整个 ZCTranslate 文件夹。
2. 模型不会随包复制：把 models 文件夹放到 exe 旁，或编辑 models-path.txt，或启动时传 --models-dir，或设置 ZC_MODELS_DIR。
3. 目标机器需要 Windows 11 x64、WebView2 和对应的 Intel 驱动。
4. data\ 如包含旧机器数据，可按需保留或删除。

八、故障排查
1. 启动失败：查看 data\logs\app.log 和 %LOCALAPPDATA%\ZCTranslate\logs\desktop-startup.log。
2. 提示模型未安装：确认 models-path.txt 指向的目录存在，或使用 --models-dir 指定。
3. NPU 加载失败：应用会自动回退 GPU/CPU；可在“设置”页查看设备与诊断信息。
4. 端口/窗口异常：从托盘右键“退出”，或结束所有 ZCTranslate 进程后重试；重复启动会自动唤起已有实例。
5. 划译无反应：确认设置中已开启、目标应用支持 UI Automation；设置页会显示桌面划译组件状态。托盘不可用时关闭窗口会直接退出。
6. 未签名提示：本程序未做代码签名，首次运行 SmartScreen 会拦截，点“更多信息”→“仍要运行”。
