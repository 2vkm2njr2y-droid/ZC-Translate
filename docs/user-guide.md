# 用户手册

## 启动

双击 `启动翻译器.bat`。首次启动会加载模型；顶部状态显示实际设备（NPU/GPU/CPU）和模型名后即可使用。

界面固定为约 620×460 的圆角小窗，不提供展开/最大化工作区。顶部标签在小窗内切换“翻译 / 文档翻译 / 术语库 / 历史 / 设置”；右侧按钮可切换深浅色主题，底部保留截图翻译、翻译记忆开关和设置快捷入口。

如果提示“未找到可用模型”，双击 `准备模型.bat`（需联网一次），或在设置页确认 `models` 目录。

## 翻译

- 源语言选“自动检测”，或手动指定中文/日语/英语。
- 目标语言不能与源语言相同；点击中间按钮交换方向。
- `Ctrl+Enter` 翻译；`Esc` 取消。
- 结果流式显示；译文下方会显示设备、耗时和速度。
- 点击“复制”取完整译文；输入框左下角的 `+` 支持导入 `.txt`/`.md`。输入框不再限制 1000 字，但会保留实时字数统计；超过约 10 万字时请分段翻译。

### 语音功能

翻译页原文框上方有两个语音按钮。语音识别和停顿检测都在本机完成，识别出的文字仍然交给当前的 Hy-MT2 翻译模型处理。

- **语音对话**：点击后持续使用默认麦克风。连续约 2.5 秒没有声音时，只提交当前这一句；整个对话不会因为停顿结束，点击“结束对话”才会停止。每句话会按时间显示原文和译文。
- **语音输入**：点击后可以连续说很长一段话；点击“停止录音”后，完整识别文字会填入原文框，不会自动翻译，再点击普通的“翻译”按钮即可翻译。
- 第一次使用点击“下载语音模型”。模型下载完成后可离线使用，当前支持中文、日语和英语。
- 语音识别使用本地麦克风和本地模型，不会把录音上传到网络。

## 截图翻译

1. 点击底部“截图翻译”，或按 **PrintScreen**。应用窗口会暂时隐藏，并打开 Windows 自带截图界面。
2. 拖选屏幕区域；松开鼠标后应用自动恢复，先做本地 OCR，再把译文覆盖到原文字位置。
3. **悬停**任意译文块：卡片变透明，原位露出截图原文；移开后恢复译文。
4. 点击译文块：底部显示完整“识别原文 / 译文 / 校验提示”；点击“关闭”收起。
5. 工具栏“原文/译文”可整体切换：隐藏所有译文块，直接查看截图。
6. 结果页可切换源语言/目标语言重新翻译，无需重新截图；运行中可点“停止”。
7. “适应”按窗口缩放；`+` / `−`、`1:1` 按钮、`Ctrl+滚轮`、双击图片都能缩放。放大后拖动图片可平移，译文卡片会随图片一起缩放并保持原位置；“复制”复制全部译文。

如果提示“未检测到截图”，通常是按了 Esc 取消，或 Windows 截图工具关闭了“自动复制到剪贴板”。请在截图工具设置中开启该选项后重试。

## 图片与文档翻译

1. 打开顶部“文档翻译”，点击“选择文件”。图片支持 PNG/JPG/BMP/WEBP/GIF；文档支持 TXT、MD、扫描 PDF 和 DOCX。
2. 选择图片后点击“图片翻译”，会进入和截图翻译相同的画布：译文覆盖在原图文字位置，可切换原文、缩放、按住鼠标拖动查看，也可点击文字块查看原文和译文对照。
3. 选择 TXT、MD、PDF 或 DOCX 后点击“翻译并生成文件”。程序会在原文件所在文件夹创建 `原文件名_翻译` 加原扩展名的新文件，原文件不会被改动。
4. Word 文档会保留原文件中的图片和大部分段落、表格结构；复杂文本框等特殊排版可能需要人工检查。
5. DOCX 会在后台逐段翻译，界面显示“已翻译 X/Y 段”、百分比和已用时间。运行中可点“取消翻译”；取消不会生成半成品文件，已完成的段落会进入翻译记忆，同一档位重试时会快速跳过。
6. 长文档建议使用 1.8B 档（更快）；7B 更准，但整本长文档可能需要数十分钟。切换档位后不会复用另一档位的翻译记忆。切到其他标签或关闭到托盘不会中断任务，点“取消翻译”或退出应用才会停止。

## 划译与托盘

1. 在“设置”页的“划译”卡片中开启“开启划译”，并选择划译目标语言；目标语言与翻译页共用。
2. 用鼠标在 Edge/Chrome、记事本、Word 等支持 Windows UI Automation 的应用中拖选文字，或双击选词、Shift+点击选区；应用会在选区上方显示悬浮译文。
3. 卡片会随流式译文实时增高；达到屏幕可用高度后在卡片内滚动，不会等全部生成完才一次性变大。卡片内可“复制”或关闭；点击卡片外部、滚动滚轮、重新选择文字或打开主窗口都会让卡片消失。源语言自动检测，模型和推理设备沿用当前设置。
4. 关闭主窗口（×、Alt+F4）只会隐藏到托盘，翻译模型继续保留；左键/双击托盘图标恢复窗口，右键菜单可开关划译或退出。
5. 再次双击启动器不会启动第二份模型：已有实例会直接显示主窗口。
6. 划译默认关闭；托盘不可用时关闭窗口会直接退出。单次划译最多 4000 字，划译内容按普通翻译写入历史与翻译记忆。

如果某种应用里选中文字没有出现卡片，通常是该应用没有向 UI Automation 暴露选区（部分自绘界面、游戏、管理员权限窗口），或当前未开启划译；设置页会显示桌面划译组件是否可用。

## 术语库

1. 点击“新建术语库”，选择源/目标语言，可开启双向。
2. 添加术语（原文 → 译文）；英文默认不区分大小写，可勾选“区分大小写”。
3. 翻译时在“术语库”下拉中选择它；模型会收到参考译法，译后还会校验是否命中。
4. CSV 列：`source,target,case_sensitive,note`；导入时表头可选，支持 UTF-8/GBK 文件（浏览器按 UTF-8 读取；GBK 建议先转码）。

## 历史与记忆

- 历史记录只在本机 SQLite；可搜索、载入、删除、清空。
- “记忆库”开启时，相同句子（同方向/模型/术语库）直接命中，不调用模型。
- 设置页可清空历史与翻译记忆。

## 设置

- **模型**：查看安装状态、加载测试、设为当前、打开模型目录、重新扫描。
- **推理设备**：自动/NPU/GPU/CPU；NPU 首次加载慢，之后走缓存。
- **生成参数**：默认官方采样（temperature 0.7 / top_p 0.6 / top_k 20），固定随机种子；可切“稳定贪心”获得完全确定的结果。
- **诊断**：检查 OpenVINO、NPU 驱动、模型、数据库、目录权限、WebView2。
- **数据与隐私**：清空翻译记忆/历史；数据目录路径。

## 常见问题

**NPU 加载失败**：确认 Intel NPU 驱动已安装；在设置中切换 GPU；查看诊断详情与 `data/logs/app.log`。

**首次翻译很慢**：NPU 首次会编译模型（约 10–15 秒）；之后从 `data/cache` 加载。

**截取后没有出现译文**：确认 Windows“截图工具”的“自动复制到剪贴板”已开启；若在截图中按了 Esc，回到应用会提示已取消。首次截图识别较慢时属正常（需加载 OCR 模型）。

**译文中出现“需复核”**：模型漏了数字/URL/占位符/术语，或长度异常。可重译、添加术语、或切换 7B。

**页面打不开/401**：请从 `启动翻译器.bat` 打开；本地 API 只接受启动器生成的一次性 token。

**7B 未安装**：运行 `准备模型.bat` 选择 quality，或执行 `prepare_model.py --profile quality`；7B 建议 GPU/CPU。准备好后可在设置中设为当前。注意仓库与发行包都不包含模型，必须先自行准备（见 README 的“模型”一节）。

## 完全离线

普通翻译运行期不需要网络；翻译模型下载只在“准备模型”阶段发生，语音模型下载只在用户点击“下载语音模型”时发生。模型准备完成后可用系统防火墙断网后重复翻译验证，或运行：

```powershell
.\.venv-runtime\Scripts\python.exe scripts\offline_check.py --device NPU
```
